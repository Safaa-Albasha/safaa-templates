# قائمة الاستكشاف الأولي (EDA) وأخطاء التحليل

1. **الصورة العامة:** حجم n، المقياس الأساسي ككل (مع n).
2. **التوزيع:** كل متغير مهم: متوسط وميديان ومدى. الذيل الطويل؟
3. **المقارنة بالمجموعات:** المقياس لكل مجموعة، **ومعه n لكل مجموعة**.
4. **العلاقات:** هل متغيران يتحركان معاً؟ ثم اسأل: شنو يربطهما؟ (ارتباط ≠ سببية)
5. **اختبر الفرق قبل ما تدّعيه:** فرق صغير بعينة صغيرة قد يكون صدفة. قاعدة تقريبية لنسبتين: z = (p1 − p2) ÷ الخطأ المعياري، و|z| > 1.96 غالباً ليس صدفة.
6. **أسئلة جديدة:** شنو فاجأك؟ شنو لازم تتأكد منه؟

## أخطاء شائعة (علّم عليها بعد كل تحليل)
- [ ] ادّعيت فرقاً بعينة صغيرة بدون n
- [ ] خلطت مجموعتين (مثلاً قناة تُذكَّر دائماً وأخرى لا) وأعطيت الفضل للتذكير
- [ ] انتقيت المقارنة اللي تعطي النتيجة اللي أريدها
- [ ] نظرت لمن بقي فقط (انحياز البقاء)
- [ ] ما فصلت بين المتوسط الكلي واتجاه كل مجموعة (مفارقة سيمبسون)
