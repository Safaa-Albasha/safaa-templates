# جدول CTQ لمخرجات الـAI (الجودة الحرجة)

CTQ = Critical To Quality: ما يهم العميل فعلاً، محوّلاً لشي يُقاس. املأه **قبل** ما تكتب الـprompt.

| # | صوت العميل (بكلماته) | الخاصية القابلة للقياس | طريقة القياس | حد القبول | شنو نسوي إذا فشل |
|---|---|---|---|---|---|
| 1 | «أريد أعرف شنو تقرر بالاجتماع» | الملخص يذكر كل القرارات | قارن بقائمة القرارات الحقيقية | 100% من القرارات | رفض + تعديل |
| 2 | «أعرف مين مسؤول» | كل مهمة لها مسؤول | عدّ المهام بلا مسؤول | صفر | رفض |
| 3 | | | | | |

قواعد:
- كل خاصية لها **رقم أو نعم/لا**، مو «جيد» أو «واضح».
- حد القبول يُكتب قبل ما ترى النتائج.
- ابدأ بـ3 خصائص فقط. زيادتها تُصعّب القياس.
