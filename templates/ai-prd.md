# PRD لميزة AI (صفحة واحدة)

| الحقل | المحتوى |
|---|---|
| **المستخدم** | من هو، وشنو سياقه |
| **المهمة (Job to be done)** | شنو يريد ينجز، بجملة |
| **ليش AI؟** | ليش مو قواعد بسيطة أو قالب؟ (إذا ما في سبب، لا تبنيها) |
| **المدخل** | شنو يعطي النظام، وبأي شكل |
| **المخرج** | شنو يطلع، وبأي شكل |
| **معيار النجاح (Evals)** | مجموعة اختبار بحجم n، ونسبة نجاح مطلوبة، كيف تُقاس |
| **حالات الفشل المتوقعة** | أخطاء محتملة وأثرها (شدة 1-10) |
| **الضوابط** | ما يرفضه النظام، وما يحتاج موافقة بشرية |
| **الإنسان بالحلقة** | من يراجع، متى، وكم ياخذ وقت |
| **كلفة المهمة** | كلفة الاستدعاء × نسبة النجاح = كلفة المهمة الناجحة |
| **الخصوصية** | شنو البيانات، من يراها، أين تُحفظ، مدة الاحتفاظ |
| **خطة الإطلاق** | داخلي ← مجموعة صغيرة ← الجميع، ومعيار الانتقال ومعيار الرجوع |
| **المؤشرات بعد الإطلاق** | جودة، كلفة، زمن، شكاوى، وكل كم نراجعها |
