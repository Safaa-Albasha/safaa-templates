# Prompt صفحة التسجيل (Chakra UI)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك مشروع React صغيراً بمكتبة Chakra UI، واجهته بالعربي من اليمين لليسار.

```
ابنِ صفحة تسجيل بالعربي (من اليمين لليسار) بمكتبة Chakra UI مع React لمشروعي.
المشروع: [سطران عن مشروعك: ماذا تقدّم، ولمن].
الأقسام: نموذج التسجيل، خطوات الطلب، رسالة تأكيد.
فعّل RTL كما في وثائق Chakra الرسمية.
لا تخترع أرقاماً أو آراء عملاء؛ اترك مكانها فارغاً.
```

## قبل أن تنشر الصفحة
1. **الأرقام والنصوص:** كل رقم (رسوم، مقاعد، تواريخ) حقيقي أو محذوف. ما تركه Claude فارغاً املأه أنت.
2. **الاتجاه ولوحة المفاتيح:** تأكد أن الحقول تبدأ من اليمين، ثم تنقّل بين الحقول بزر Tab واختر الخيارات بالأسهم. إذا انعكس الاتجاه فتأكد من `dir="rtl"` و`LocaleProvider`.
3. **الإرسال:** زر الإرسال في الملف شكل فقط ولا يرسل شيئاً. اربطه بخدمة نماذج أو ببريدك، ولا تجمع بيانات الطلاب قبل أن تعرف أين تُحفظ ومن يراها.

## إذا عندك بطاقة مشروع
