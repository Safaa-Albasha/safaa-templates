# Prompt عارض المنتج ثلاثي الأبعاد (three.js)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك ملف HTML واحداً فيه المنتج يدور داخل صفحة عربية من اليمين لليسار.

```
أضف عارض منتج ثلاثي الأبعاد بـthree.js لصفحتي العربية (من اليمين لليسار).
المنتج: [اسمه، وملف GLB إن وجد].
المطلوب: يدور ببطء، ويقلّبه الزبون بإصبعه، و3 أزرار للألوان.
على الجهاز الضعيف: صورة ثابتة بدل المشهد.
لا تخترع أسعاراً أو مواصفات؛ اترك مكانها فارغاً.
سلّمني ملف HTML واحداً.
```

## قبل أن تنشر الصفحة
1. **النموذج نفسه:** المجسّم يطابق منتجك الحقيقي (الشكل واللون والمقاس). إذا لم يكن عندك ملف GLB فما يرسمه Claude تقريب، لا صورة للمنتج؛ لا تبع به.
2. **الهاتف:** افتح الصفحة على هاتف عادي، لا على أحدث جهاز. إذا تأخر ظهور المنتج أو سخن الجهاز فاطلب تصغير الملف أو استعمال الصورة الثابتة.
3. **الأسعار والمواصفات:** كل سعر ومقاس في الصفحة حقيقي. ما تركه Claude فارغاً املأه أنت أو احذفه.
