# Prompt لوحة التحكم (Material UI)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك مشروع React صغيراً بمكتبة Material UI، واجهته بالعربي من اليمين لليسار.

```
ابنِ لوحة تحكم بالعربي (من اليمين لليسار) بمكتبة Material UI مع React لمشروعي.
المشروع: [سطران عن مشروعك: ماذا تقدّم، ولمن].
الشاشات: ملخص اليوم، قائمة المواعيد، نموذج حجز.
فعّل RTL بطريقة وثائق MUI الرسمية.
لا تخترع أرقاماً أو آراء عملاء؛ اترك مكانها فارغاً.
```

## قبل أن تنشر الصفحة
1. **الأرقام والأسماء:** كل رقم أو اسم عميل في اللوحة حقيقي أو محذوف. ما تركه Claude فارغاً املأه أنت.
2. **الاتجاه:** افتح نموذج الحجز وتأكد أن عناوين الحقول وأسهم القوائم على اليمين. إذا ظهرت على اليسار فإعداد RTL ناقص (اطلب من Claude إضافة `stylis-plugin-rtl` كما في وثائق MUI).
3. **البيانات:** القوائم والنماذج في المشروع شكل فقط ولا تحفظ شيئاً. اربطها بقاعدة بيانات أو بجدول قبل أن يستخدمها أحد.

## إذا عندك بطاقة مشروع
ارفع [بطاقة المشروع](../project-card.md) مع الطلب، وأضف سطراً: «اكتب النصوص بنبرة البطاقة».
