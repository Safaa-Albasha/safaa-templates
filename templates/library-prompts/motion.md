# Prompt صفحة حجز تتجاوب مع الضغط (Motion)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك ملف HTML واحداً لصفحة حجز عربية، أزرارها وقوائمها تتحرك بمكتبة Motion (اسمها السابق Framer Motion).

```
أضف حركة بـMotion لصفحة الحجز العربية (من اليمين لليسار).
الصفحة: [الصق الكود أو صف الصفحة].
المطلوب: زر الحجز ينضغط ويرجع بنابض، والمواعيد تدخل بالتتابع، ورسالة تأكيد واضحة بعد الحجز.
احترم إعداد «تقليل الحركة» في الجهاز.
لا تخترع أوقاتاً أو أسعاراً؛ اترك مكانها فارغاً.
سلّمني ملف HTML واحداً.
```

## قبل أن تنشر الصفحة
1. **الحجز الحقيقي:** رسالة «تم الحجز» في الملف شكل فقط ولا تحجز شيئاً. اربط الزر بنظام المواعيد عندك قبل النشر، وإلا سيظن الزبون أن موعده محجوز.
2. **الأوقات:** كل وقت معروض حقيقي ومتاح. ما تركه Claude فارغاً املأه أنت.
3. **تقليل الحركة:** فعّل «تقليل الحركة» في إعدادات هاتفك وافتح الصفحة: يجب أن تعمل الأزرار وتظهر رسالة التأكيد بلا ارتداد.
