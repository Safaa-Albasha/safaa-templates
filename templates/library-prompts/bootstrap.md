# Prompt صفحة الهبوط (Bootstrap)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك ملف HTML واحداً بمكتبة Bootstrap 5 (نسخة RTL)، تفتحه بالمتصفح مباشرة.

```
ابنِ صفحة هبوط بالعربي (من اليمين لليسار)
لمشروعي بـBootstrap 5 (ملف bootstrap.rtl).
المشروع: [سطران عن مشروعك: ماذا تبيع، ولمن].
الأقسام: عنوان وزر، 3 مزايا، الأسعار، أسئلة شائعة، نموذج تواصل.
الألوان: [لونان من هويتك].
لا تخترع أرقاماً أو آراء زبائن؛ اترك مكانها فارغاً.
سلّمني ملف HTML واحداً.
```

## قبل أن تنشر الصفحة
1. **الأرقام والآراء:** كل رقم أو رأي زبون في الصفحة حقيقي وعندك ما يثبته. ما تركه Claude فارغاً املأه أنت أو احذفه.
2. **ملف RTL:** تأكد أن الرابط في الصفحة يشير إلى `bootstrap.rtl.min.css` لا `bootstrap.min.css`، وأن `<html>` فيه `dir="rtl"`. بدونهما تنعكس المسافات والقوائم.
3. **النموذج:** نموذج التواصل شكل فقط ولا يرسل شيئاً. اربطه بخدمة نماذج أو ببريدك قبل النشر.
