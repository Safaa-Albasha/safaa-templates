# Prompt صفحة الهبوط (daisyUI)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك ملف HTML واحداً بمكتبة daisyUI فوق Tailwind CSS، تفتحه بالمتصفح مباشرة.

```
ابنِ صفحة هبوط بالعربي (من اليمين لليسار)
لمشروعي بـdaisyUI فوق Tailwind CSS.
المشروع: [سطران عن مشروعك: ماذا تبيع، ولمن].
الأقسام: عنوان وزر، 3 مزايا، الأسعار، أسئلة شائعة، نموذج تواصل.
الثيم: [ثيم جاهز أو لونان من هويتك].
لا تخترع أرقاماً أو آراء زبائن؛ اترك مكانها فارغاً.
سلّمني ملف HTML واحداً.
```

اختر الثيم من صفحة الثيمات في daisyui.com، واكتب اسمه كما هو (مثل `cupcake` أو `dracula`).

## قبل أن تنشر الصفحة
1. **الأرقام والآراء:** كل رقم أو رأي زبون في الصفحة حقيقي وعندك ما يثبته. ما تركه Claude فارغاً املأه أنت أو احذفه.
2. **الثيم:** غيّر قيمة `data-theme` في وسم `<html>` إلى ثيم آخر وافتح الصفحة: إذا لم تتغير الألوان كلها فبعض الألوان مكتوبة يدوياً، فاطلب من Claude استعمال ألوان الثيم (`btn-primary`، `bg-base-100`).
3. **النموذج:** نموذج التواصل شكل فقط ولا يرسل شيئاً. اربطه بخدمة نماذج أو ببريدك قبل النشر.
