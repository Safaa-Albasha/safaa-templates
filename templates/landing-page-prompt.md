# Prompt صفحة الهبوط (Tailwind CSS)

انسخ الطلب كما هو إلى Claude، واملأ ما بين القوسين. يعطيك ملف HTML واحداً تفتحه بالمتصفح مباشرة.

```
ابنِ صفحة هبوط بالعربي (من اليمين لليسار) بـTailwind CSS لمشروعي.
المشروع: [سطران عن مشروعك: ماذا تبيع، ولمن].
الأقسام: عنوان وزر، 3 مزايا، الأسعار، أسئلة شائعة، نموذج تواصل.
الألوان: [لونان من هويتك].
لا تخترع أرقاماً أو آراء زبائن؛ اترك مكانها فارغاً.
سلّمني ملف HTML واحداً.
```

## قبل أن تنشر الصفحة
1. **الأرقام والآراء:** كل رقم أو رأي زبون في الصفحة حقيقي وعندك ما يثبته. ما تركه Claude فارغاً املأه أنت أو احذفه.
2. **الهاتف:** افتح الصفحة على هاتفك وتأكد أن الأقسام لا تخرج عن الشاشة.
3. **النموذج:** نموذج التواصل في الملف شكل فقط ولا يرسل شيئاً. اربطه بخدمة نماذج أو ببريدك قبل النشر.

## إذا عندك بطاقة مشروع
ارفع [بطاقة المشروع](project-card.md) مع الطلب، وأضف سطراً: «اكتب النصوص بنبرة البطاقة». يطلع النص بصوت مشروعك بدل النص العام.
