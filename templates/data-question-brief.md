# ورقة سؤال البيانات (قبل ما تفتح أي ملف)

| الحقل | اكتب |
|---|---|
| القرار اللي ينتظر هذا التحليل | مين يقرر؟ شنو الخيارات؟ |
| السؤال (جملة وحدة، قابلة للإجابة بالأرقام) | |
| المقياس الأساسي وتعريفه الدقيق | مثال: نسبة عدم الحضور = المواعيد اللي ما حضر لها ÷ كل المواعيد المحجوزة (بدون الملغاة) |
| المجموعات اللي نقارن بينها | |
| البيانات اللازمة ومصدرها | |
| الفترة الزمنية | |
| ما الذي يغيّر قرارك؟ | لو طلعت النتيجة X نسوي كذا، ولو Y نسوي كذا |
| ما الذي لا نعرفه (حدود) | |

قاعدة: إذا ما أقدر أقول «شنو يتغير حسب النتيجة»، السؤال غير جاهز.
