## جدول الاستخراج
| الجزء | ما وجدته |
|---|---|
| المهمة | رد مهذب وقصير على إيميل عميل |
| المدخلات | نص إيميل العميل |
| القواعد | يبدأ بالشكر؛ موعد التسليم = «خلال يومي عمل»؛ لا وعد بسعر. **من الأمثلة فقط:** 3 أسطر، توقيع «فريق خدمة العملاء»، أسئلة السعر تُحال لفريق المبيعات |
| شكل النتيجة | 3 أسطر: شكر، جواب، توقيع |
| الحدود | لا أسعار ولا خصومات ولا مواعيد غير «يومي عمل» |
| متى يُستخدم | «رد على إيميل العميل»، «جاوب العميل» |
