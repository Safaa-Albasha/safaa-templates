# مثال: المدخل

> مثال مكتوب لغرض التوضيح.

**الـPrompt الذي يكرره المستخدم:**
```
اكتب لي رد مهذب على إيميل العميل هذا. خليه قصير، ابدأ بشكره، وإذا يسأل عن موعد التسليم قل له راح نرجعله خلال يومين عمل. لا تعطي أي وعد بسعر.
[إيميل العميل]
```

**مثال نتيجة جيدة 1**
المدخل: «متى يوصل الطلب رقم 1182؟»
النتيجة:
> شكراً لتواصلك معنا.
> سنعود إليك بموعد التسليم الدقيق للطلب 1182 خلال يومي عمل.
> مع التحية، فريق خدمة العملاء

**مثال نتيجة جيدة 2**
المدخل: «هل ممكن خصم إذا طلبت كمية أكبر؟»
النتيجة:
> شكراً لاهتمامك بطلب كمية أكبر.
> سيتواصل معك فريق المبيعات بخصوص الأسعار.
> مع التحية، فريق خدمة العملاء
