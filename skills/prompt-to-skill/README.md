# من Prompt إلى Skill (`prompt-to-skill`)

**لمن:** من يكتب أو يلصق نفس الـPrompt كل يوم، ويريد أن يحوّله إلى Skill يعمل وحده.

**ماذا يفعل:**
1. يطلب منك الـPrompt ومثالين لنتيجة أعجبتك.
2. يستخرج منها: المهمة، المدخلات، القواعد (حتى المخفية في أمثلتك)، شكل النتيجة، والحدود.
3. يكتب مجلد الـSkill كاملاً (`SKILL.md` ومثال).
4. يجرّبه مرة واحدة على أحد أمثلتك، ويخبرك بما غيّره بعد التجربة.

**كيف تبدأ:** اكتب لـClaude «حوّل هذا الـPrompt إلى Skill» والصق الـPrompt ومثالين.

**مهم:** تجربة واحدة فحص سريع، وليست دليلاً على الجودة. إذا أردت أن تتعلم بناء Skill وقياسه على 10 أمثلة وتحسينه، استخدم لوحة [`skill-building-canvas`](../../templates/skill-building-canvas.md) (الـSkill `skill-builder` لم يُنشر بعد).

**حدوده:**
- لا يضيف قواعد أو معلومات غير موجودة في الـPrompt أو الأمثلة.
- يحذف كلمات المرور والبيانات الشخصية من الأمثلة ويضع مكانها فراغات.
- Prompt واحد = Skill واحد.

**حالة الاختبار:** فحص سريع على مثال واحد (n=1). التفاصيل في [`TEST-RESULTS.md`](TEST-RESULTS.md).
